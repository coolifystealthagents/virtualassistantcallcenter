## Map callers to business context

Architecture firms receive calls about active projects, new site work, proposal invitations, consultants, invoices, and document requests. Route by the caller’s purpose and project context, not only by the person’s name. A new inquiry should reach business development, while a construction-phase question needs the project contact or documented alternate.

## Build a short intake

Collect the caller’s name, company, callback number, project or site, reason for calling, and desired response. For a new opportunity, ask for location, project type, decision timeline, and the requested next conversation. Do not promise design availability, approvals, scope, or a proposal deadline.

## Preserve the thread

Every transfer or callback note should carry forward the project name, question, attachments mentioned, and next owner. If a project contact is unavailable, use a visible queue and state the follow-up expectation accurately. A complete message prevents the caller from explaining the same site conditions twice.

## Measure routing quality

Review misrouted calls, incomplete project references, duplicate callbacks, and aging messages. Coach the intake around the error that creates the most rework. Keep the routing map small enough that a new caller can choose a path confidently.

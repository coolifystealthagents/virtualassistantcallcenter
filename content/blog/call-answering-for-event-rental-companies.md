## Identify the event need

Ask what the caller is planning, which items they are considering, the event date, and what answer they need. A tent inquiry, table request, delivery question, and damage report should not enter the same queue.

## Capture delivery and setup context

Record the venue address, access restrictions, setup timing, pickup timing, guest context when relevant, and callback number. Do not confirm inventory, delivery, or setup until the responsible owner checks it.

## Route changes and damage reports

For an active order, note the order reference and exact change requested. For damage or missing items, record what is affected and where it was found. Send the request to the approved owner without assigning blame or promising a remedy.

## Keep the next step visible

The handoff should state the event date, location, request, and open decision. Review calls for missing venue access notes and vague inventory descriptions. Small changes to the opening can prevent avoidable follow-up calls.

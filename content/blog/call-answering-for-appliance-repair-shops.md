## Identify the appliance and problem

Start with the appliance type, the caller’s description of the symptom, and whether the unit is still running. Ask for the brand or model only when the repair team uses it for routing. Avoid diagnosing the fault or suggesting an unsafe repair over the phone.

## Ask about the service setting

Record the address, best callback number, access restrictions, and any detail that affects arrival. If water, gas, smoke, or electrical danger is reported, use the approved safety escalation language and route the call to the proper owner.

## Set a careful next step

The caller should know whether the request is being sent for scheduling, review, or a callback. Give only approved timing language. A service request is not complete until the record names the owner and the action still required.

## Use notes to improve routing

Sample completed calls for missing appliance types, vague symptoms, and unassigned follow-ups. If the same field is absent in several records, make it part of the opening. Keep optional questions out of the path unless they change the next decision.

## Confirm the operating calendar

Holiday coverage starts with one approved calendar. Record each location's closing time, reopening time, reduced staffing period, and time zone. Name the person who approves changes and the channel where the current version lives. A virtual assistant should not have to reconcile a website banner, an old email, and a manager's chat message while a caller waits.

Mark ordinary closures separately from emergency changes. Include an effective timestamp so the call team knows when a temporary message begins and ends. If a location has not confirmed its schedule, label it unresolved and route questions to its owner instead of guessing.

## Write messages for common caller needs

Prepare short responses for appointment requests, order or service status, urgent service needs, and general questions. Each response should state what is known, what the assistant can do now, and when the caller should expect the next update. Avoid promising that a closed team will respond before its approved return time.

Give the assistant one safe phrase for unknown situations: capture the request, read back the contact details, and send it to the designated owner. The phrase should protect the caller from false certainty without sounding evasive.

## Map routing and fallback ownership

Assign a primary and backup destination for each call category. Test that phone numbers, queues, and notification rules work before the holiday period begins. If the primary owner does not acknowledge a routed item within the documented window, the record should move to the backup path without requiring the assistant to invent a new escalation.

After normal hours resume, review unanswered calls, stale callbacks, and temporary instructions. Remove expired messages promptly. A brief review of what callers asked can improve the next holiday plan without preserving unnecessary caller details.

## Separate a request from a confirmed change

Treat the caller's preferred time as a request until an authorized person or system confirms availability. Repeat the current appointment, requested change, location, service, and contact method. Avoid canceling the original slot before the replacement is secured unless policy explicitly requires it.

## Define edit and exception authority

List which appointment types the assistant may move, how far in advance changes are allowed, and which cases require a scheduler. Double bookings, deposits, linked appointments, clinical preparation, travel windows, and repeated changes should have named exception owners.

## Send one clear confirmation

After the calendar update, read back the date, time, time zone, location, provider, and any changed instructions. Record who made the change and how the confirmation was delivered. If confirmation fails, place the request in a visible follow-up queue with a deadline and owner.

A daily reconciliation between reschedule notes and calendar edits catches requests that were recorded but never completed. Measure unresolved requests, not just completed calls.

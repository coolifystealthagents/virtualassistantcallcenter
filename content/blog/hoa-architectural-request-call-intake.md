## Identify the property and project

Collect the caller's name, property address, community, callback details, and a short description of the proposed work. Ask whether an application has already been submitted and record its reference number. Keep a new request separate from a status question or a compliance notice.

## Check for missing documents only

The approved checklist may call for drawings, colors, measurements, contractor information, or neighbor acknowledgments. A phone assistant can say which listed items are absent from the record. The assistant should not decide that the package is complete or predict approval.

## Keep rules with the reviewer

Do not interpret covenants, say that another home's project created a precedent, or grant permission to begin. Record any deadline or hearing date the caller mentions, then send the question to the community manager or architectural review contact.

## Give a traceable next step

Confirm the request type, submission status, missing-item note, and destination queue. State the published review window if one exists. The call record should make it possible for the next person to answer without asking the homeowner to repeat the whole story.

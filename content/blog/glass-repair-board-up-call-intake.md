# Emergency glass and board-up calls: capture exposure, occupancy, and access facts

## Define the first decision

The first decision is not whether the glass-repair caller is right. ## Capture facts that change the glass-repair handoff

A useful glass-repair intake record contains fields that affect routing, preparation, authority, or follow-up. ## Put authority beside the question

The main stop condition is telling anyone to handle broken glass, enter an unsafe area, certify structural safety, promise police response, or guarantee a board-up time.

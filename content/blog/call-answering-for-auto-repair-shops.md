## Separate the reasons people call

An auto repair phone workflow should distinguish appointment requests, estimate questions, repair-status calls, parts delays, and roadside concerns. Each reason needs a clear next step. A caller asking whether a vehicle is ready should reach the service record owner, while a new repair request needs vehicle details and preferred timing before scheduling.

## Capture vehicle context early

Ask for the caller’s name, callback number, vehicle make and model, and the reason for calling. Add the license plate or work-order reference only when the shop’s approved process calls for it. Repeat the callback number and write the requested action in plain language. Avoid guessing about diagnosis, safety, completion time, or warranty coverage.

## Make handoffs useful

When a technician or service adviser receives a message, include the vehicle context, caller’s exact question, urgency, and promised next step. If the right person is unavailable, place the call in a named callback queue with a due time. Review missed calls by reason each week so the shop can fix the most common unanswered path.

## Check the workflow with real scenarios

Test a routine oil-service booking, an estimate request with missing information, a repair-status question, and a roadside escalation. The workflow succeeds when the caller does not need to repeat the story and the shop can see who owns the next action.

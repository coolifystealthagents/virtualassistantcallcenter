## Identify the order or visit

Furniture-store calls usually concern a showroom visit, product question, delivery, order change, return, or damaged item. Ask for the caller’s goal first. An order-status question should reach fulfillment, while a design or product question may belong to showroom staff.

## Capture useful retail context

Record name, callback number, order or item reference when available, delivery address if approved, and requested response. Note deadlines such as a move date without promising delivery. Do not invent inventory, condition, return eligibility, or delivery windows.

## Keep delivery messages actionable

Include the item, order reference, issue, preferred callback method, and owner. For a delivery concern, capture access constraints and the customer’s exact request. Read back what was recorded so the caller can correct a missing detail before the message is routed.

## Reduce repeat contacts

Review calls caused by missing order references, unclear store locations, or inconsistent return directions. Improve the opening question that would have prevented each repeat. Clear routing protects the customer’s time and helps showroom staff stay focused on in-person service.

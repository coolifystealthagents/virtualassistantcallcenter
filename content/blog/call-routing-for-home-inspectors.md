## Sort by inspection stage

A home inspector’s phone line handles new booking requests, arrival questions, report access, realtor coordination, and post-inspection clarifications. The stage of the inspection determines the next owner. Route report interpretation and technical questions to the inspector rather than treating them as simple scheduling matters.

## Capture property and timing

Ask for the caller’s name, callback number, property address, transaction or inspection reference if available, and requested response. For a new booking, note property type, preferred date range, and access conditions. Do not promise report delivery, findings, or a specific inspection duration without confirmation.

## Keep the report request intact

Write the caller’s question in their own words, including the report section or access problem mentioned. Add the deadline and preferred callback method. If an inspector is unavailable, assign the request to a visible queue instead of asking the caller to keep trying.

## Improve the routing map

Review calls that moved between booking and inspection staff, especially when a property address was missing. Use those examples to refine the opening questions. Accuracy at intake saves time for inspectors and reduces confusion during a time-sensitive transaction.

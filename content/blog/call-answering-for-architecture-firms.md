## Find the project signal

Capture property type, project stage, location, caller role, desired service, and timeline. A prospective owner needs a different route from a contractor calling about an active drawing set. A concise intake prevents senior designers from reconstructing the first conversation.

## Keep design advice with the firm

Phone coverage may explain how to share drawings or request a consultation, but it should not interpret code, approve a design change, or estimate feasibility. A Philippines-based call specialist can record the question and identify the architect who should answer it.

## Screen access and confidentiality

Ask whether the caller is authorized to discuss an active project before sharing any status. Do not request sensitive plans through an unapproved channel. Record the document type or question category and direct the caller to the firm’s stated process.

## Make the handoff decision-ready

Repeat the property, project stage, request, timing, and callback route. If the firm needs a portfolio or project brief before a consultation, state that requirement without promising acceptance or a start date.
